# 용어집 (글에서 이 표기로 고정)

| 표기 | 의미 |
|---|---|
| Verdict | 루브릭(기준×척도×단계)을 판정기로 채점하고 집계하는 평가 엔진 |
| 파일 루브릭 | 파일 단위로 10개 기준(0~5점)을 채점해 100점으로 환산하는 루브릭 |
| repo 루브릭 | 저장소 전체 지표 9종(커버리지, 중복, 복잡도 등)을 수식으로 종합하는 루브릭 |
| 기준선 | 개선 작업 시작 시점(2026-11-07)의 측정값 |
| 줄 수 가중 평균 | 파일 점수를 줄 수로 가중한 평균. 큰 파일의 영향이 커진다 |
| 작업 묶음 | 같은 패턴으로 리팩터링한 PR들의 그룹 (B01~B05) |
| 스코어보드 | 매 편 끝의 고정 형식 요약 표 |
| 판정 모델 | 파일을 채점하는 모델. 같은 파일도 실행마다 점수가 조금 다를 수 있다 |

## 10개 파일 기준
testability, analysability, dead_code, error_handling, file_length, cohesion, types, naming, comments, unchecked_casts

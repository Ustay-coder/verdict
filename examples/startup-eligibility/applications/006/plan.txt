□ 창업 아이템 개요(요약)
아이템명: AI 기반 개별화 독서·학습 코칭 SaaS
학습자의 독서 기록, 풀이 패턴, 이해도 데이터를 분석해 개인별 읽기·학습 경로와 과제를 추천하는 에듀테크 SaaS

1. 문제 인식 (Problem)
현재 학습 현장에서는 같은 교재와 같은 진도로 수업이 진행되더라도 학생별 이해도와 학습 속도 차이가 크게 나타난다. 특히 읽기 이해, 요약, 문제 해결 단계에서 학생마다 막히는 지점이 달라 교사 한 명이 모든 학생의 상태를 세밀하게 파악하기 어렵다. 그 결과 학습 부진은 누적되고, 학생은 자신에게 맞지 않는 난이도와 분량 때문에 흥미를 잃기 쉽다.

학부모 역시 자녀의 학습 상태를 객관적으로 확인하기 어렵다. 시험 점수만으로는 어떤 개념이 부족한지, 어떤 읽기 습관이 필요한지 알 수 없고, 사교육에 의존하더라도 맞춤형 피드백을 지속적으로 받기 어렵다. 학교와 가정 사이의 학습 정보가 단절되어 있어, 학습 문제를 조기에 발견하고 개입하는 체계가 부족하다.

또한 기존 디지털 학습 도구는 정답 여부 중심의 단순 문제풀이에 치우치는 경우가 많아, 학습자의 사고 과정과 독서 습관을 충분히 반영하지 못한다. 에듀테크 시장은 확대되고 있으나, 실제 현장에서는 “무엇을 얼마나 풀었는가”보다 “어디에서 왜 막히는가”를 설명해 주는 서비스가 부족하다. 이 공백이 본 아이템의 필요성을 만든다.

2. 실현 가능성 (Solution)
본 사업은 AI 기반 개별화 독서·학습 코칭 SaaS를 제공한다. 학습자가 읽은 글, 작성한 요약, 문제 풀이 결과, 오답 유형, 체류 시간 등의 데이터를 축적해 이해도와 학습 성향을 분석하고, 이를 바탕으로 개인별 읽기 자료, 복습 순서, 난이도 조절 과제를 추천한다. 핵심은 단순한 콘텐츠 제공이 아니라, 학습자의 현재 수준을 진단하고 다음 행동을 제시하는 코칭 구조이다.

서비스는 웹과 모바일에서 모두 이용 가능하도록 설계하며, 교사용 대시보드와 학부모용 리포트를 함께 제공한다. 교사는 학급 전체의 취약 영역과 학생별 학습 패턴을 한눈에 확인할 수 있고, 학부모는 자녀의 변화 추이와 추천 과제를 확인할 수 있다. 학생에게는 짧고 반복 가능한 학습 루틴을 제시해 부담을 낮추고 지속 이용률을 높인다.

기술적으로는 자연어 처리와 추천 알고리즘을 활용해 독서 내용 이해도와 서술형 응답을 분석하고, 학습 로그를 기반으로 개인화 규칙을 지속적으로 고도화한다. 초기에는 국어·독해 중심으로 시작한 뒤, 점차 사회·과학 텍스트와 자기주도학습 영역으로 확장한다. 복잡한 하드웨어 없이 클라우드 기반으로 운영 가능해 초기 구축비와 유지비 부담이 낮다.

3. 성장전략 (Scale-up)
초기 시장은 초등 고학년부터 중학생을 중심으로 공략한다. 이 구간은 읽기 이해와 학습 습관 형성이 중요하고, 학부모의 관심도 높아 유료 전환 가능성이 크다. 먼저 학원, 공부방, 소규모 교육기관과 협력해 파일럿 적용을 진행하고, 사용성과 효과를 검증한 뒤 학교와 가정용 구독 모델로 확장한다.

수익모델은 월 구독형 SaaS를 기본으로 하며, 기관용 좌석 과금과 학부모용 개인 구독을 병행한다. 추가로 진단 리포트, 심화 학습 패키지, 교사용 관리 기능을 유료 옵션으로 제공해 객단가를 높인다. 장기적으로는 누적된 비식별 학습 데이터를 활용해 콘텐츠 기업과 협력 가능한 인사이트형 서비스도 검토한다.

성장 단계에서는 콘텐츠 제휴와 유통 파트너십이 중요하다. 다양한 읽기 자료와 연계 가능한 콘텐츠 생태계를 구축하고, 학습 데이터 기반 성과 사례를 확보해 재구매율과 추천율을 높인다. 또한 학습 성취 개선을 보여주는 정량 지표를 축적해 입소문 중심의 확산을 유도한다. 해외 진출은 한국어 독서 코칭 모델을 다국어 학습 보조로 전환할 수 있는 중장기 과제로 설정한다.

4. 팀 구성 (Team)
당사는 2024년 초기창업패키지에 선정되어 협약을 체결하고 시제품 개발을 수행한 바 있다.
대표자는 에듀테크 서비스 기획과 교육 현장 문제 정의를 총괄한다. 사업 초기에는 교사와 학부모, 학생의 요구를 세밀하게 반영하는 제품 설계를 중심으로 역할을 수행하며, 시장 검증과 고객 인터뷰를 통해 서비스 우선순위를 정한다. 또한 외부 협력사와의 제휴, 사업 운영, 지표 관리까지 총괄하는 실행 책임을 맡는다.

팀원 A는 AI 모델 설계와 데이터 분석을 담당한다. 학습 로그 구조를 설계하고, 독서 이해도 추정과 추천 로직을 구현하며, 서비스 사용 데이터의 품질을 관리한다. 팀원 B는 프런트엔드와 백엔드 개발을 맡아 교사·학생·학부모 화면을 구현하고, 안정적인 서비스 운영과 보안 체계를 구축한다. 각 역할이 분리되어 있어 개발과 사업이 병행 가능한 구조다.

팀원 C는 교육 콘텐츠 기획과 사용자 경험을 담당한다. 학습 난이도 구간별 콘텐츠 편성, 과제 흐름 설계, 리포트 문구 최적화를 통해 실제 사용성을 높인다. 대표자와 기술·콘텐츠 담당이 긴밀히 협업하여 제품-시장 적합성을 빠르게 검증하고, 초기 고객의 피드백을 반영해 기능을 반복 개선하는 체계를 갖춘다.

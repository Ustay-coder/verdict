# Verdict

## Score anything against your rubric, through one API

Write your grading criteria in YAML. Send a PDF, a URL, a YouTube link or JSON. Get back a total, a grade,
pass/fail and a score for every criterion.

```yaml
name: Startup pitch review
criteria:
  - id: problem
    name: Problem clarity
    anchors: { "1": No clear problem, "3": Stated but vague, "5": "Specific, painful, quantified" }
  - id: safe
    name: Brand safe
    scale: { type: binary, labels: [unsafe, safe] }
aggregation: { method: weighted_mean, normalize: [0, 100], passThreshold: 55 }
```

```bash
curl -s https://verdict-api.example.workers.dev/v1/evaluations \
  -H "authorization: Bearer $VERDICT_API_KEY" -H "content-type: application/json" \
  -d '{"rubric":"rub_startup_pitch","inputs":[{"type":"url","url":"https://acme.example"}]}'
```

Verdict scores with decision models (Jev, Clef) instead of chat models, so you get probabilities instead of
prose. You can also add human raters and deterministic checks to the same rubric.

### Use it from

REST, a CLI, an MCP server for agents, or the TypeScript SDK.

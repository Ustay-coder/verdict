# Receipt Run

Expense reports for small-business owners and bookkeepers: photograph a receipt, and Receipt Run categorises it, matches it to the card charge and exports it to the accounting tool.

**Built this weekend:** the mobile capture app, the receipt-to-charge matching, and exports to two accounting tools. **Already existed:** a commercial OCR API and the accounting tools' official SDKs.

40 pilot users at 3 companies submitted their expenses through it during the event. We used GitHub Copilot for autocomplete across the app.

Demo (2:10): https://video.example.org/receipt-run · Code: https://git.example.org/receipt-run

**Limits:** handwritten receipts fail OCR, and expense apps are a crowded category.

# 캡션이 쓸 수 있는 사실
- 24초 화면 녹화: 위는 verdict watch(실시간 심사 결과 화면), 아래는 Claude Code.
- 가상의 건강기능식품(바나바잎 추출물) 스마트스토어 상세페이지를 Verdict로 심사했다.
- 루브릭은 실제 광고 규정에서 가져온 6가지 기준이다: 질병 치료·의약품 오인(걸리면 0점), 인정 문구를 넘는 효과 표현, 효과를 입증하는 듯한 후기, 의사·약사 추천, '판매 1위'·'식약처 인증' 같은 과장, 필수 표시 정보 누락.
- 원본 상세페이지에는 이 6가지 문제가 모두 있었다. 예: "당뇨를 치료하며, 혈당약을 끊을 수 있습니다", "효과 100% 보장", "공복혈당이 130에서 98로" 후기, "현직 약사 추천", "판매 1위".
- 에이전트는 한 회차에 문제 하나만 고치고 다시 심사했다.
- 점수: 0 → 14 → 29 → 43 → 58 → 75 → 94. 7회차에 '게시 가능'(90점 이상)으로 통과했다. 91초, 사람 개입 없음.
- 의사·약사 추천 광고 제재는 2026년 11월 27일부터 시행되는 개정 식품표시광고법 내용이다.
- Verdict는 루브릭(기준)을 정하면 AI 심사·사람·자동 검사로 점수를 매기는 평가 엔진이다.
- 자동 심사는 법률 검토를 대신하지 않는다.
- 독자: 스마트스토어 셀러, 온라인 마케터, 브랜드 담당자.
